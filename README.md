# Mapeamento Objeto Relacional

Repositório de apoio à disciplina **Mapeamento Objeto Relacional**, do curso de **Sistemas de Informação – Graduação**.

Este repositório reúne os materiais utilizados ao longo do semestre, servindo como base para o estudo da persistência de dados em aplicações orientadas a objetos, utilizando frameworks de Mapeamento Objeto Relacional (ORM) e boas práticas de desenvolvimento de software.

---

# 🎯 Sobre a disciplina

A disciplina tem como objetivo desenvolver a capacidade de projetar e implementar soluções utilizando Mapeamento Objeto Relacional (ORM), integrando aplicações orientadas a objetos a bancos de dados relacionais de forma eficiente, segura e aderente às boas práticas de desenvolvimento. 

Durante o semestre serão explorados conceitos e técnicas relacionados a:

* Modelagem orientada a objetos;
* Diagramas de classes e multiplicidade;
* Mapeamento entre classes e tabelas;
* Utilização de anotações de persistência;
* Relacionamentos entre entidades;
* Operações de persistência (CRUD);
* Frameworks ORM;
* Boas práticas de organização, reutilização e manutenção do código.

Toda a disciplina será conduzida de forma prática, utilizando estudos de caso e desenvolvimento de aplicações com persistência em bancos de dados relacionais. 

---

# 🧠 Objetivos de Aprendizagem

Ao final da disciplina o estudante será capaz de:

* compreender os conceitos de Mapeamento Objeto Relacional (ORM);
* modelar entidades persistentes utilizando orientação a objetos;
* aplicar anotações para mapear classes e tabelas;
* implementar relacionamentos entre entidades;
* utilizar um framework ORM para persistência de dados;
* realizar operações de consulta, inserção, atualização e remoção de objetos;
* compreender o ciclo de vida das entidades;
* aplicar boas práticas de desenvolvimento na camada de persistência;
* identificar e corrigir inconsistências de mapeamento entre objetos e bancos de dados.
